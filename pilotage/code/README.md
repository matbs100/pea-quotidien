# 🔎 Rapports du vérificateur du code

Chaque jour à 4 h, l'agent « Vérificateur du code » (consigne `VERIFICATION.md`), sous la direction du chef
d'orchestre, vérifie la confidentialité du propriétaire (aucune information personnelle dans le dépôt
public ni sur le site), contrôle que le code est bien fait et marche, fait au plus une correction testée,
apprend une technique de code dans une source fiable et propose une idée. Le chef relit son travail à 5 h.
