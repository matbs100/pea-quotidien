## Ce que j'ai appris
- Les recherches GitHub par **sujet** (`--topic stock-screener`) donnent de bien meilleurs résultats que les mots-clés libres.
- Les projets les plus suivis de suivi de patrimoine (Ghostfolio, Wealthfolio) sont sous **AGPL** : on peut s'inspirer de leurs idées, mais pas reprendre leur code dans un projet public sans le passer sous la même licence.
- **quantstats** (Apache-2.0) est la référence des rapports de performance : ratio de Sharpe, de Sortino, pires baisses, rendements mensuels. Ce sont de bons candidats pour la fiche détaillée.
- Aucun projet open source trouvé n'est centré sur le **PEA français**. La combinaison ETF éligibles + SRI + frais plafonnés + TTF est une vraie spécificité de Matin PEA.

## À retenir
Avant de reprendre du code open source, regarder sa licence : MIT, BSD et Apache-2.0 permettent de le réutiliser en le citant, alors que GPL et AGPL imposent de publier son propre projet sous la même licence.
