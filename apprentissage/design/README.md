# Apprentissage de l'agent design

L'agent design (`DESIGN.md`, chaque nuit à 1 h 30) range ici ce qu'il apprend :

- `lecons.md` : **sa mémoire**, relue chaque nuit en premier : ce qui a marché, ce qui a été annulé et pourquoi, les souhaits du propriétaire, les erreurs à ne plus refaire ;
- `motifs.md` : le catalogue des bonnes idées vues ailleurs (où, quel problème elles règlent, comment les appliquer ici, statut) ;
- `etudes/AAAA-MM-JJ.md` : l'étude de marché de la nuit (3 sources de catégories différentes) ;
- `journal/AAAA-MM-JJ.md` : note de la page (grille), changement fait, ce qui a été appris, avis du chef.

Garde-fou : `scripts/design.py` (aucune information retirée, contrastes, accessibilité) et le contrôle
« Design » de `scripts/controle.py`. Déplacements volontaires : `pilotage/design/deplacements.json`.
