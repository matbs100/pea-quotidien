# Étude de marché du 2026-11-14

Rotation : a (GitHub), f (références sérieuses) ×2. Demain : b (sites originaux), c (pages faites avec Claude), d (Shopify).

## a. GitHub · https://github.com/topics/finance-dashboard
Vu : tableaux de bord financiers très étoilés (≈15 à 97 étoiles), surtout Power BI / React / Streamlit ; licences non visibles sur la page du sujet, donc rien copié. Tendance commune : cartes de chiffres + un petit graphique, détail derrière un clic.
Pourquoi c'est plus clair : une carte = un chiffre, une variation, une courbe. Ici : garder cette règle et éviter qu'une ligne de texte se coupe de façon maladroite.

## f. GOV.UK Design System, composant Details · https://design-system.service.gov.uk/components/details/
Vu : cacher le détail réservé à une minorité derrière un intitulé court et descriptif ; ne jamais cacher ce que la majorité doit lire ; certains utilisateurs hésitent à cliquer.
Pourquoi : allège la page sans rien retirer. Ici : un intitulé « Voir plus » qui annonce le contenu pour les blocs longs (analyse, signaux).

## f. Nielsen Norman Group, divulgation progressive · https://www.nngroup.com/articles/progressive-disclosure/
Vu : deux niveaux au plus, bouton évident, l'essentiel d'abord ; ce qu'on voit est perçu comme important.
Pourquoi : moins d'erreurs pour les novices. Ici : l'analyse du jour montre « Le marché en une phrase » d'abord, le reste derrière un bouton.
