# 📚 Connaissances vérifiées

Ce que les agents apprennent, rangé par thème. **Chaque fait a une source et un statut.** L'agent de
nuit ajoute les faits avec « ⏳ à vérifier » ; le chef d'orchestre les vérifie le matin avec une source
ouverte le jour même (officielle pour la réglementation et la fiscalité).

| Fichier | Thème |

| [Marchés](marches.md) | fonctionnement des marchés, séances, indices, actualité qui compte |
| [Méthodes](methodes.md) | indicateurs, études sur leur efficacité, limites |
| [Réglementation](reglementation.md) | PEA : règles, plafonds, frais, fiscalité |
| [Données](donnees.md) | sources de données, leurs limites et leurs pièges |
| [Design](design.md) | esthétique, lisibilité, accessibilité, facilité d'utilisation |

## Format d'une entrée
```
- **Notion** : explication courte, avec ses propres mots. Source : [titre](lien), lu le AAAA-MM-JJ.
  Statut : ⏳ à vérifier
```
« lu le » seulement si la page a vraiment été ouverte et lue ; sinon « Source proposée : [titre](lien) ».

Statuts : `⏳ à vérifier`, `✅ vérifié le AAAA-MM-JJ (source)`, `❌ corrigé le AAAA-MM-JJ : fait exact (source)`,
`❔ non vérifiable le AAAA-MM-JJ : raison`.
