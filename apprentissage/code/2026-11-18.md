# Technique apprise
`overflow: hidden` fait de l'élément un conteneur de défilement (on peut le faire défiler par script), alors que `overflow: clip` rogne seulement, sans conteneur. Sur iOS, un `body` en `hidden` peut bloquer le glissement du doigt ; `clip` évite ce piège. Source : developer.mozilla.org, page « overflow », lue le 18/11/2026. Statut : ⏳ à vérifier par le chef.
