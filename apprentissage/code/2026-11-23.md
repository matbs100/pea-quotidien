# Technique apprise
**Puits sûrs et puits dangereux (XSS).** Source : OWASP Cheat Sheet Series, « Cross Site Scripting Prevention »,
lue le 23/11/2026. Un « puits » est l'endroit où une variable entre dans la page. `textContent`, `value`,
`setAttribute` (nom sûr) traitent la variable comme du texte : elle ne s'exécute jamais. `innerHTML`, lui, interprète
le HTML : il faut échapper la donnée ou la nettoyer. Le modèle de la fiche construit des gabarits `innerHTML` :
la règle est donc d'envelopper chaque donnée externe dans `esc(...)`, comme le fait déjà `ligne()`. Statut : ⏳ à vérifier par le chef.

# Idée pour Matin PEA
Un test qui parcourt `modele.html`, repère chaque `${...}` placé dans un gabarit `innerHTML` et exige `esc(`, un
