# Technique apprise
`Path.read_text/write_text(encoding=...)` : sans `encoding`, Python prend l'encodage du système, donc le résultat peut changer d'une machine à l'autre ; toujours écrire `encoding="utf-8"`. À l'inverse, `Path.walk()` n'existe qu'à partir de Python 3.12 : inutilisable sur le Mac (3.9), où `os.walk` reste la solution.
Source : docs.python.org (pathlib), lu le 14/11/2026. Statut ⏳ à vérifier par le chef.
