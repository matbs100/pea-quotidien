# 💻 Ce que le vérificateur du code apprend

Une page par jour : la veille des mises à jour (Python, bibliothèques du projet, failles connues, web,
outils et *skills* des agents), une technique de code expliquée avec ses propres mots, une lecture (PDF,
journal technique ou documentation) et une idée pour Matin PEA. Seulement des sources fiables, listées
dans [[Finance/PEA Quotidien/pilotage/sources-verifiees|les sources vérifiées]] ; chaque fait reste « ⏳ à
vérifier » jusqu'à la relecture du chef.
