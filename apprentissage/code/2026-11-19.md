# Technique apprise
La documentation de `datetime` (docs.python.org, lue le 19/11) distingue les objets « naïfs » (sans fuseau) des objets « avertis ». `date.today()` est naïf : il dépend de la machine. `datetime.now(ZoneInfo("Europe/Paris")).date()` donne le même jour sur le Mac et dans le cloud en UTC, ce que fait `scripts/paris.py`. Statut : ⏳ à vérifier par le chef.
