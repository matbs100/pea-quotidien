# Technique apprise
**« Patcher là où l'objet est cherché »** (docs.python.org, `unittest.mock`, lu le 13/11). `patch()` change le nom qui pointe vers un objet, pas l'objet lui-même : il faut remplacer le nom utilisé par le code testé, pas celui de sa définition. Un faux posé à la main (`module.f = lambda …`) doit toujours être rendu dans un `try/finally`, comme le fait `scripts/tests.py` ; `patch.dict` rend un dictionnaire à l'identique à la sortie du bloc. Statut : ⏳ à vérifier par le chef.
