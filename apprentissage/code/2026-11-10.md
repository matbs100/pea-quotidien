# Technique apprise
**Politique de sécurité de contenu (CSP) : empreintes et `strict-dynamic`.** Une CSP peut autoriser un script
par son empreinte (hash) ou par un nonce généré à chaque réponse ; avec `strict-dynamic`, un script ainsi
approuvé peut en charger d'autres. Le projet utilise des empreintes, adaptées à une page statique (pas de
serveur pour générer un nonce).
Source : MDN, guide « Content Security Policy », lu le 10/11/2026 (`robots.txt` lu, lecture autorisée).
Statut : ⏳ à vérifier par le chef.
