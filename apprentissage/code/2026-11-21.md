# Technique apprise
La directive CSP `frame-ancestors` dit quelles pages ont le droit d'intégrer la nôtre dans un cadre : c'est la protection contre le détournement de clic (clickjacking), qui remplace l'ancien `X-Frame-Options`. Elle ne fonctionne pas dans une balise `<meta>`, seulement en en-tête HTTP : sur un site statique, la protection n'est donc pas possible depuis la page seule. Source : developer.mozilla.org, lu le 21/11. ⏳ à vérifier par le chef.
