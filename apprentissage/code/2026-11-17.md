# Technique apprise
- ⏳ À vérifier par le chef. `ZoneInfo(clé)` (docs.python.org, module zoneinfo, lu le 17/11) cherche le fichier de fuseau dans `TZPATH`, puis dans le paquet `tzdata`. Sur une machine sans base de fuseaux (cloud minimal), il faut donc `tzdata` ; sinon `ZoneInfo("Europe/Paris")` échoue. Utile pour les dates de la fiche : `date.today()` donne l'heure du serveur, pas celle de Paris.
