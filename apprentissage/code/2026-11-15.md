# Technique apprise
`zoneinfo` (Python 3.9+) : les heures avec fuseau gèrent seules le changement d'heure, et pour une heure ambiguë (retour à l'heure d'hiver) l'attribut `fold` choisit l'avant (0) ou l'après (1). Sans données de fuseaux sur le système, le module se rabat sur le paquet `tzdata` de PyPI : sur une machine minimale, il faudrait l'ajouter aux dépendances. Le projet utilise `ZoneInfo("Europe/Paris")` partout, ce qui convient au Mac.
Source : docs.python.org (zoneinfo, version 3.9), lu le 15/11/2026. Statut ⏳ à vérifier par le chef.
