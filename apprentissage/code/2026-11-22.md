# Technique apprise
Une CSP stricte repose sur des empreintes (hash) pour le code statique ou des nonces pour le code généré : seuls les scripts portant la bonne empreinte s'exécutent, ce qui bloque aussi les gestionnaires inline et `eval()`. Avant de l'imposer, on la déploie avec l'en-tête `Content-Security-Policy-Report-Only` : le navigateur signale les violations sans rien bloquer. Source : developer.mozilla.org, lu le 22/11. ⏳ à vérifier par le chef.
