# Technique apprise
- ⏳ Politique de sécurité (CSP), MDN, lu le 2026-11-11 : un CSP n'est pas un substitut à l'échappement des données ; il bloque les scripts en ligne sans empreinte ou nonce, les gestionnaires d'événements en ligne, les URL `javascript:` et `eval()`. Le mot-clé `unsafe-inline` annule cette protection pour les scripts : le projet ne l'utilise que pour les styles.
- Statut : à vérifier par le chef.
