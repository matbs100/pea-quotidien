# Technique apprise
La politique de sécurité de contenu (CSP) limite ce qu'une page peut charger et exécuter ; elle protège surtout contre l'injection de script (XSS). `object-src 'none'` bloque `<object>` et `<embed>` ; `base-uri 'none'` empêche une balise `<base>` injectée de rediriger les liens relatifs. Source : developer.mozilla.org, lu le 20/11. ⏳ à vérifier par le chef.
