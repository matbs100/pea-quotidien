# Technique apprise
**Content Security Policy (CSP)** (MDN, lu le 26/11/2026) : suite d'instructions qu'un site envoie au navigateur pour limiter ce que le code de la page peut charger et faire. Son usage principal est de contrôler les ressources JavaScript chargées, donc de freiner les attaques par injection de script (XSS) ; elle sert aussi contre l'intégration abusive dans un cadre (clickjacking) et pour forcer le https. Pour Matin PEA : la politique de la page est une défense de plus, qui ne remplace pas l'échappement des données. Statut : ⏳ à vérifier par le chef.
