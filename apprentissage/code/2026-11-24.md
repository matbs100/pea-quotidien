# Technique apprise
Source : OWASP, fiche « Cross Site Scripting Prevention » (cheatsheetseries.owasp.org, lue le 24/11/2026). Statut : ⏳ à vérifier par le chef.
Avec mes mots : le plus sûr est d'écrire une donnée dans la page comme du texte (`textContent`), qui ne s'exécute jamais. Quand on doit utiliser `innerHTML`, chaque donnée passe d'abord par une fonction d'échappement, ou par un nettoyeur reconnu. Le gabarit du projet suit la seconde voie avec `esc()` : un test qui vérifie que chaque `${...}` y passe attrapera un oubli futur.
